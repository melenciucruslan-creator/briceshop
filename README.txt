BRICESHOP — современный серый дизайн

Файлы: index.html, styles.css, app.js.

Запуск:
1. Распакуй ZIP.
2. Открой папку BRICESHOP в Visual Studio Code.
3. Открой index.html в Safari либо запусти расширение Live Server.

Важно: это frontend-прототип. Добавленные товары и фото хранятся только в браузере; форма заказа пока не отправляет заказ и не отправляет письмо. Для реальных продаж необходимо сделать backend, базу данных, закрытый вход администратора, почтовые уведомления и развернуть сайт по HTTPS. Оплату при получении нужно согласовать с перевозчиком. Не размещай секретные данные или номера банковских карт в коде сайта.
